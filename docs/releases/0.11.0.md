# Assegai Auth 0.11.0

Auth 0.11.0 aligns the package and its current installation guidance with the AssegaiPHP 0.11 framework release line. Session, JWT, and OAuth strategy APIs are unchanged.

## Dependency compatibility

- PHP 8.4 or newer remains required.
- The Attributes requirement remains `^1.0`, preserving Auth 0.10.0's published consumer range. Auth's unchanged use of `Injectable` requires no newer API floor.
- The coordinated release recommends Attributes `1.0.3` through the inventory's `~1.0.3` installation constraint. This recommendation does not narrow Auth's dependency compatibility range.
- Auth has no direct runtime dependency on Core or Common and remains usable in standalone PHP applications.

## Upgrade

For a standalone installation:

```bash
composer require assegaiphp/auth:^0.11 --with-all-dependencies
```

For a Core application adopting the coordinated `0.11.x` release, review all directly required framework modules and their support ranges together. For example, an application directly requiring Core and Auth can explicitly select the new release line with:

```bash
composer require assegaiphp/core:^0.11 assegaiphp/auth:^0.11 --with-all-dependencies
```

Include any other directly required framework modules in the same reviewed update, preserving existing support ranges the application still needs. Composer's `--with-all-dependencies` option permits dependency updates; it does not rewrite other root constraints that still select an earlier framework line.

Auth's existing session-login configuration and strategy calls remain supported. See [Session Login End to End](../session-login.md) for the current framework integration guide.
