# Assegai Auth 0.11.0

Auth 0.11.0 aligns the package and its current installation guidance with the AssegaiPHP 0.11 framework release line. Session, JWT, and OAuth strategy APIs are unchanged.

## Dependency compatibility

- PHP 8.4 or newer remains required.
- The Attributes requirement changes from `^1.0` to `~1.0.3`. This raises the minimum to `1.0.3` and removes automatic acceptance of Attributes `1.1` and later minor lines. Compatible `1.0.x` patches remain accepted.
- Attributes retains its established `1.0.x` dependency stream under the framework's coordinated release matrix.
- Auth has no direct runtime dependency on Core or Common and remains usable in standalone PHP applications.

## Upgrade

For a standalone installation:

```bash
composer require assegaiphp/auth:^0.11 --with-all-dependencies
```

For a Core application, review all directly required framework modules and move their constraints to `0.11.x` together. For example, an application directly requiring Core and Auth can update both requirements with:

```bash
composer require assegaiphp/core:^0.11 assegaiphp/auth:^0.11 --with-all-dependencies
```

Include any other directly required framework modules in the same reviewed update. Composer's `--with-all-dependencies` option permits dependency updates; it does not rewrite other root constraints that still select an earlier framework line.

Auth's existing session-login configuration and strategy calls remain supported. See [Session Login End to End](../session-login.md) for the current framework integration guide.
